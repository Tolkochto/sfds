# Easy Motion: Виртуальный AI-коуч 🏋

Система компьютерного зрения (Computer Vision) для автоматической оценки техники выполнения физических упражнений (пауэрлифтинг) и танцевальных движений. 

Проект сравнивает движения пользователя с эталонным видео (референсом профессионального тренера), нивелируя разницу в ракурсе, антропометрии и темпе выполнения, и выводит метрики точности в реальном времени.

## 🎯 Основные цели и задачи проекта
Главная задача — разработать алгоритм, способный сопоставлять два независимых видеопотока, оценивать правильность углов и амплитуды движений пользователя относительно эталона.

* **Бизнес-метрика:** Повышение вовлеченности (Retention Rate) пользователей фитнес-приложений, геймификация тренировок и монетизация AI-тренера.
* **Техническая метрика:** Центрированное косинусное сходство (*Cosine Similarity*) для оценки геометрии позы и взвешенное пиксельное расстояние (*Weighted Distance*) для оценки амплитуды и смещений. Идеальное значение Cosine Similarity $\rightarrow 1.0$.

## 📊 Данные и их трансформация
* **Входные данные:** Видеоролики пользователя и коуча в формате `.mp4`.
* **Пайплайн трансформации:**
  1. Покадровая разбивка видеоряда с помощью OpenCV.
  2. Масштабирование (downscale) кадров $>720p$ для оптимизации использования RAM.
  3. Конвертация цветового пространства BGR $\rightarrow$ RGB.
  4. Преобразование кадров в PyTorch тензоры.
  5. Извлечение координат 17 ключевых точек (Keypoints) в формате COCO-датасета.
  6. Векторизация координат (массивы `np.float32` размерностью $17 \times 2$) для временного выравнивания.

## ⚙️ Алгоритмы и этапы работы
Проект реализован в 5 логических этапов:
1. **Детекция скелета:** Инференс предобученной модели `Keypoint R-CNN` (ResNet50 FPN) на GPU для извлечения координат суставов.
2. **Математический модуль:** Расчет метрик сходства на основе векторов.
3. **Прокрустов анализ:** Применение матрицы аффинных преобразований (Метод наименьших квадратов) для масштабирования и переноса скелета пользователя под пропорции эталона.
4. **Синхронизация темпа:** Интеграция алгоритма **Dynamic Time Warping (DTW)** для выравнивания временных рядов движений. Алгоритм находит оптимальный путь сопоставления кадров, решая проблему рассинхрона.
5. **Рендеринг результата:** Сборка синхронизированного видео с наложением скелетов (эталонного и трансформированного пользовательского) и выводом метрик на оригинальный фон.
