# Easy Motion: Виртуальный AI-коуч по пауэрлифтингу 🏋️‍♂️

Система компьютерного зрения (Computer Vision) для автоматической оценки техники выполнения силовых упражнений (на примере базового движения — приседания). 

Проект сравнивает биомеханику движений атлета с эталонным видео (референсом профессионального тренера Дмитрия Головинского), нивелируя разницу в ракурсе, антропометрии и темпе выполнения, и выводит метрики точности прямо на экран в реальном времени.

## 🎯 Основные цели и задачи проекта

* **Главная задача** — разработать алгоритм, способный сопоставлять два независимых видеопотока, оценивать правильность углов, глубину седа и общую траекторию движений относительно эталона.
* **Бизнес-метрика:** Повышение вовлеченности (Retention Rate) пользователей фитнес-приложений и монетизация AI-тренера.
* **Техническая метрика:** Центрированное косинусное сходство (Cosine Similarity) для оценки геометрии позы и взвешенное пиксельное расстояние (Weighted Distance) для оценки амплитуды и смещений. Идеальное значение Cosine Similarity → 1.0.

## 📊 Данные и их трансформация

**Входные данные:** Видеоролики выполнения приседаний (пользовательский и эталонный) в формате `.mp4`.

**Пайплайн трансформации:**
1. Покадровая разбивка видеоряда с помощью OpenCV.
2. Масштабирование (downscale) кадров > 720p для оптимизации использования RAM.
3. Конвертация цветового пространства `BGR` → `RGB`.
4. Преобразование кадров в `PyTorch` тензоры.
5. Извлечение координат 17 ключевых точек (Keypoints) в формате COCO-датасета.
6. Векторизация координат (массивы `np.float32` размерностью 17×2) для временного выравнивания.

## ⚙️ Алгоритмы и этапы работы

Проект реализован в 5 логических этапов:

1. **Детекция скелета:** Инференс предобученной модели Keypoint R-CNN (ResNet50 FPN) на GPU для извлечения координат суставов.
2. **Математический модуль:** Расчет метрик сходства на основе векторов.
3. **Прокрустов анализ:** Применение матрицы аффинных преобразований (Метод наименьших квадратов) для масштабирования и переноса **эталонного скелета тренера под антропометрические пропорции пользователя**.
4. **Синхронизация темпа:** Интеграция алгоритма Dynamic Time Warping (DTW) для выравнивания временных рядов движений. Алгоритм находит оптимальный путь сопоставления кадров, решая проблему рассинхрона (например, разной скорости прохождения "мертвой точки" в приседе).
5. **Рендеринг результата:** Сборка синхронизированного видео с наложением каркасов (зеленого эталонного и красного пользовательского) и выводом метрик на оригинальный фон.

## Инструкция по установке (Installation)

Для запуска проекта локально или на сервере выполните следующие шаги:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Tolkochto/sfds.git
   cd sfds/EasyMotion_Project
   ```
2. Создайте и активируйте виртуальное окружение (рекомендуется):
  ```bash
  python3 -m venv venv
  source venv/bin/activate  # Для Linux/Mac
  venv\Scripts\activate     # Для Windows
   ```
3. Установите необходимые зависимости:
  ```bash
  pip install -r requirements.txt
   ```
## Как запускать проект

Основной пайплайн запускается напрямую из командной строки терминала.

  ```bash
  python scripts/main.py --ref <путь_к_эталону> --target <путь_к_вашему_видео> --output <куда_сохранить>
   ```
Пример запуска на тестовых данных:
  ```bash
  python scripts/main.py \
  --ref data/ref_squat.mp4 \
  --target data/my_squat.mp4 \
  --output results/final_squat.mp4
   ```

**Что должно получиться на выходе:**

Скрипт выведет в консоль процесс обработки через прогресс-бары `tqdm` (парсинг видео, DTW, рендеринг). В указанной папке появится итоговый видеофайл `.mp4`. На видео поверх движущегося пользователя будет наложен красный скелет (суставы пользователя) и зеленый скелет (идеальная траектория тренера, адаптированная под пропорции пользователя). В левом верхнем углу в реальном времени будут отображаться метрики `Cos Sim` (целевое значение ~1.0) и `W-Dist`.
