# Проект CV-4.  Перенос стиля на мобильном устройстве

Прототип мобильного приложения для переноса стиля на изображения, вдохновленный Prisma. Главная особенность проекта — все вычисления (инференс) нейросети происходят полностью на устройстве пользователя (On-Device ML), без использования облачных вычислений и серверов.

## Описание проекта

В рамках данного проекта была решена задача запуска тяжелой модели машинного обучения на мобильном устройстве в условиях ограниченных ресурсов. Для этого использовалась готовая архитектура переноса стиля (Arbitrary Image Stylization), которая была оптимизирована, квантована и конвертирована в формат TensorFlow Lite.

## Структура репозитория

*   **/app** — Исходный код Android-приложения (Kotlin). Содержит UI-компоненты и логику работы с камерой/галереей, а также интеграцию TFLite-модели (файлы `MainActivity.kt`, `StyleTransferHelper.kt` и др.).
*   **/model** — Python-скрипты для работы с нейросетью:
    *   `train.py` и `utils.py` — код для загрузки, обработки датасетов и подготовки модели.
    *   `convert.py` — скрипт для перевода модели в мобильный формат `.tflite`.
    *   `requirements.txt` — зависимости для Python-окружения.
*   **app-debug.apk**[cite: 1] — Готовый скомпилированный установочный файл Android-прототипа для быстрой демонстрации.

## Стек технологий

*   **Machine Learning:** Python, TensorFlow, TensorFlow Lite, TensorFlow Hub.
*   **Mobile Development:** Android SDK, Kotlin, XML, Gradle.
